# 美らや-八重岳別邸-(rooms/1085130495032365685)新ハウスルール対応 修正案

作成日: 2026-11-17 / 適用: 2026-11-20以降の確定予約
※【要確認】はホスト画面での確認が必要な箇所。

## 結論
新形式のハウスルール欄はほぼ対応済み。違反の可能性が高い記載は無く、整合性と置き場所の修正が中心。

## 1. 要修正

### 1-1. 定員と「添い寝のお子様」の矛盾
- 現状: 標準ルールの定員は6人、「安全と宿泊施設」欄も最大6人(乳幼児を除く)。
  一方、追加ルールには「6名様に加えて添い寝のお子様2名まで可、1泊3000円(7名目・8名目のみ)」とある。
- 問題: 最大8名のように読め、定員と一致しない。料金も追加ルール内の文章になっている。
- 修正案:
  - 実際に受け入れるなら、定員を8人に変更し、追加ゲスト料金(Airbnbの料金設定)で3,000円/泊を設定する。
    予約時の表示料金に含まれるため、ポリシーに沿う。
  - 受け入れないなら、追加ルールの該当文を削除する。
  - 追加ルールに残す場合の文案: 「6名様を超えるご宿泊をご希望の場合は、予約前にご連絡ください。」

### 1-2. BBQの記載を予約時に見える場所へ
- 現状: 「その他の特記事項」(説明文内)に「BBQの持ち込みは禁止。ご希望の場合は指定の配達業者をご案内(機材+食材込み)」。
  説明文には「BBQ(別料金)」とも書かれている。
- 問題: ルールが説明文の特記事項にしかなく、所定のハウスルール欄に載っていない。
- 修正案:
  - 追加ルール(滞在中): 「BBQの持ち込みはできません。ご希望の場合は、指定の配達業者(機材・食材込みの有料サービス)をご案内しますので、事前にご連絡ください。」
  - 料金は、任意の有料サービスとして書くなら可(金額を明記)。
  - 特記事項側の同じ文は削除し、二重記載を避ける。

## 2. 設定の確認(標準ルール)
現在の標準ルール: 定員6人 / ペット不可 / 禁煙(電子タバコ含む) / パーティー・イベント不可 / 商業目的の撮影禁止。
- 【要確認】「騒音禁止の時間帯」「チェックアウト時の施錠」が未設定に見える。運用があれば設定する。
- 【要確認】旧「チェックアウト手順」に書いていた内容(鍵・施錠など)が消えていないか。

## 3. 問題なし(そのままでよい)
- 「鍵のかかったクロゼット以外はご自由に」: 宣伝している設備へのアクセス制限ではないので可。
- 旅館業法の許可番号の記載、一酸化炭素検知器・火災報知器の設置、防犯カメラの開示。
- 罰金・追加料金・清掃の依頼は見当たらない。
